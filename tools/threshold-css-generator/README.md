# CCFOLIA ステータス閾値CSS作成ツール

CCFOLIAのステータスゲージを、残量に応じて色分け・アニメーションさせるCSSを画面上で作成するツールです。静的なHTML・CSS・JavaScriptだけで動作します。

**公開ページ：**

https://aoko2477.github.io/ccfolia-css/tools/threshold-css-generator/

## 対応する表示形式

### キャラクター一覧

キャラクター一覧に表示されるステータスを対象にします。

- ベースCSS：`modified-code/status-all.css`
- Stylish：`modified-code/status-all-stylish.css`
- OBSブラウザソースのURL：

```text
https://ccfolia.com/rooms/{ルームID}/
```

### 指定キャラクターのステータス表示

URLで指定した1人のキャラクターに表示されるステータスを対象にします。

- ベースCSS：`status/fixed-status.css`
- Stylish：`status/fixed-status-stylish.css`
- OBSブラウザソースのURL：

```text
https://ccfolia.com/rooms/{ルームID}/characters/{キャラクターID}
```

## 機能

- ベースCSS
  - 標準
  - Stylish
  - 追加しない
- 閾値を適用する対象
  - すべてのステータス
  - 1つのステータス
  - 複数のステータス（例：`1, 3, 4`）
- 危険域・注意域の閾値指定
- 通常色・注意色・危険色の指定
- ステータスごとの通常色
  - HP・MP・SANプリセット
  - 対象番号・表示名・色の編集
  - 行の追加と削除
- 危険域のアニメーション
  - なし
  - 短く2回点滅
  - 一定リズムで点滅
  - 心拍
  - 強い心拍
- 簡易プレビュー
- OBSブラウザソース用URLの案内
- CSSのコピーとファイル保存
- 作成後の設定変更を「未反映」として通知

## 初期設定

| 項目           | 初期値              |
| -------------- | ------------------- |
| 表示形式       | キャラクター一覧    |
| ベースCSS      | Stylish             |
| 適用対象       | 1番目のステータス   |
| 危険域         | 20%以下             |
| 注意域         | 50%以下             |
| 通常色         | ベースCSSの色を使用 |
| 注意色         | `#f1c40f`           |
| 危険色         | `#e74c3c`           |
| アニメーション | 強い心拍            |
| 開始までの遅延 | 0.2秒               |

ステータスごとの通常色は初期状態では無効です。有効にすると、次のプリセットを使用できます。

| 対象番号 | 表示名 | 色        |
| -------- | ------ | --------- |
| 1        | HP     | `#2ecc71` |
| 2        | MP     | `#3498db` |
| 3        | SAN    | `#6a6a6a` |

## 閾値の判定

危険域20%、注意域50%の場合は次のように判定します。

| 残量        | 表示   |
| ----------- | ------ |
| 0〜20%      | 危険色 |
| 20%超〜50%  | 注意色 |
| 50%超〜100% | 通常色 |

境界値の例：

```text
20%   → 危険色
20.1% → 注意色
50%   → 注意色
50.1% → 通常色
```

CSSに数値比較がないため、整数値と小数値の`style`属性セレクタを列挙して判定します。

## CSSの作成順

作成されるCSSは次の順番で構成されます。

```text
ベースCSSの @import
→ 色・アニメーション変数
→ 通常色の補正
→ ステータスごとの通常色
→ 注意域
→ 危険域
```

ステータスごとの通常色と閾値色分けを同時に使う場合、通常域では個別色、注意域では注意色、危険域では危険色が適用されます。

`fixed-status`では通常色を指定しない限り、ベースCSS側の色やグラデーションを維持します。

## 使い方

1. 表示形式を選びます。
2. ベースCSSを選びます。
3. 適用対象、閾値、色、アニメーションを設定します。
4. 必要に応じて「詳細設定」からステータスごとの通常色を有効にします。
5. 「CSSを作成」を押します。
6. 作成されたCSSをOBSブラウザソースのカスタムCSSへ貼り付けます。

作成後に設定を変更すると、結果は「未反映」になります。再度「CSSを作成」を押すまで、コピーとファイル保存は無効になります。

## 注意事項

- このツールは非公式です。
- CCFOLIA・OBSのアップデートでHTML構造が変わると、作成したCSSが動作しなくなる場合があります。
- 問題が発生しても、CCFOLIAまたはOBSの公式サポートへ問い合わせないでください。
- 独自のベースCSSとの組み合わせは動作保証外です。
