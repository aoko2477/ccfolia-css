CCFOLIA / CUSTOM CSS

ステータス閾値 CSS 作成ツール

適用するステータス、危険域・注意域の閾値、色、アニメーションを選んで、 OBS用カスタムCSSを作成できます。

HP
2 / 11
非公式ツールです。 CCFOLIA・OBSのアップデートにより動作しなくなる場合があります。 問題が発生した際、公式へ問い合わせないでください。

使い方
  1. キャラクター一覧または指定キャラクターの表示形式を選びます。
  2. ベースにするステータス一覧CSSを選びます。
  3. 対象・閾値・色・演出を選びます。
  4. 「CSSを作成」を押します。
  5. 作成されたCSSをOBSのブラウザソースのカスタムCSSへ貼り付けます。

標準またはStylishを選ぶと、必要な @import も作成結果へ含まれます。 独自のステータス一覧CSSを使う場合は「追加しない」を選び、そのCSSより後ろへ作成結果を貼り付けてください。
